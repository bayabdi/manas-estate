# ТЗ: сайт-визитка + миникаталог недвижимости

Дата: 2026-05-06

## Цель
Сделать MVP-лендинг для GitHub Pages по Instagram-профилю `@jalal_abad__nedvijimost`, чтобы посетитель быстро понял услуги агентства, посмотрел пример объектов и написал в WhatsApp/Instagram.

## MVP
- Один статический `index.html` для GitHub Pages.
- Визитка: hero, услуги, процесс, контакты.
- Миникаталог: 6 придуманых демо-объектов до получения реальных данных.
- На каждой карточке: тип, статус, район, цена, краткие характеристики и кнопка WhatsApp.
- Ясное предупреждение, что это демо-объекты для MVP.
- Без отдельной админ-панели; реальные объекты ведутся через Google Sheet.

## Не входит сейчас
- Авторизация и отдельная админ-панель.
- База данных.
- Автоматический импорт Instagram.
- Онлайн-бронирование/CRM.

## Критерии готовности
- `index.html` содержит секцию миникаталога минимум с 6 карточками.
- Есть CTA на WhatsApp и Instagram.
- Сайт работает как статический файл без сборки.
- README объясняет публикацию на GitHub Pages.
